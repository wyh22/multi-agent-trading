# company_comparison

## Purpose

对多个明确指定的上市公司执行横向研究比较。该 Skill 负责组织多标的证据并综合差异，不允许用单一公司的结论替代其他公司的独立取证。

## When to use

- 用户明确给出至少两个股票代码，并要求比较财务、经营或研究维度。
- 单股票问题不应调用本 Skill。

## Inputs

- `tickers`: 至少两个股票代码，当前执行器限制最多处理少量标的以控制成本。
- `as_of_date`: 统一研究截止日期。
- `objective`: 用户希望比较的维度。

## Execution

1. 对每个标的分别调用现有专业研究能力获取证据。
2. 保持统一 `as_of_date`，避免不同公司使用不同时间口径。
3. 汇总各公司独立证据。
4. 对用户要求的维度做结构化比较与综合说明。

## Output

- 多公司横向比较结果。
- 对缺失数据的公司显式标记 unavailable / no data。

## Constraints

- 至少两个不同 ticker。
- 每个公司的事实必须来自该公司的独立证据。
- 不把比较结果转化为自动下单行为。
